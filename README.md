คู่มือการใช้งานระบบ (User Manual)
1. องค์ประกอบของระบบ (System Components) ระบบเครื่องให้อาหารสัตว์เลี้ยงอัจฉริยะ ประกอบด้วยทรัพยากรซอฟต์แวร์สำคัญ 4 ส่วน ดังนี้:
AutoCatFeeder.ino: ซอร์สโค้ดภาษา C++ สำหรับควบคุมไมโครคอนโทรลเลอร์ ESP32 และอ่านค่าจากเซนเซอร์
Code.gs: ซอร์สโค้ดส่วนบริการจัดการหลังบ้าน (Back-end) ทำหน้าที่เป็น API ผ่านบริการ Google Apps Script เพื่อเชื่อมต่อฐานข้อมูลและประมวลผลร่วมกับปัญญาประดิษฐ์ (AI)
index.html: ซอร์สโค้ดส่วนติดต่อผู้ใช้งาน (Front-end Dashboard) สำหรับการแสดงผลข้อมูลสถานะแบบเรียลไทม์ (Real-time)
Database.xlsx: โครงสร้างไฟล์ฐานข้อมูลสำหรับจัดเก็บสถิติการทำงานและโปรไฟล์ของสัตว์เลี้ยง
2. การเตรียมความพร้อมด้านซอฟต์แวร์และไลบรารี (Software Pre-requisites) ก่อนเริ่มกระบวนการติดตั้ง ผู้พัฒนาจำเป็นต้องจัดเตรียมโปรแกรม Arduino IDE และติดตั้งไลบรารี (Library) ที่จำเป็นเพื่อให้ไมโครคอนโทรลเลอร์สามารถสื่อสารกับอุปกรณ์เซนเซอร์ได้ โดยเข้าไปที่เมนู Sketch > Include Library > Manage Libraries... และดำเนินการค้นหาเพื่อติดตั้งไลบรารีดังต่อไปนี้:
ESP32Servo: ไลบรารีสำหรับการควบคุมองศาของมอเตอร์เซอร์โว (Servo Motor) บนแพลตฟอร์ม ESP32
HX711 : ไลบรารีสำหรับแปลงและอ่านค่าพิกัดน้ำหนักจากเซนเซอร์ Load Cell ผ่านโมดูลขยายสัญญาณ HX711
3. ขั้นตอนการติดตั้งระบบ (Installation Procedures)
3.1 การจัดการฐานข้อมูลคลาวด์ (Google Sheets Configuration)
นำเข้าไฟล์ Database.xlsx ไปยังบัญชี Google Drive ของผู้ปฏิบัติงาน และเลือกเปิดด้วยรูปแบบ Google Sheets
ตรวจสอบโครงสร้างแผ่นงาน (Worksheets) โดยต้องประกอบด้วย 2 แผ่นงานหลัก ได้แก่ Sheet1 (สำหรับบันทึกข้อมูลเซนเซอร์) และ CatProfile (สำหรับจัดเก็บข้อมูลและผลวิเคราะห์โภชนาการจาก AI)
3.2 การปรับแต่งระบบประมวลผลและ Web Dashboard (Apps Script Configuration)
ในหน้าต่าง Google Sheets เข้าไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
นำเนื้อหาจากไฟล์ Code.gs ไปวางลงในพื้นที่เขียนสคริปต์ และระบุรหัส Gemini API Key ในตัวแปร GEMINI_API_KEY ให้สมบูรณ์
สร้างไฟล์ประเภท HTML ใหม่ในโครงการ Apps Script โดยตั้งชื่อว่า index จากนั้นนำเนื้อหาจากไฟล์ index.html ไปวางทับเนื้อหาเดิม
ดำเนินการ Deploy (ทำให้ใช้งานได้) เป็น Web App โดยเข้าไปที่ การทำให้ใช้งานได้รายการใหม่ เลือกประเภทเป็น เว็บแอป และกำหนดสิทธิ์การเข้าถึง (Who has access) เป็น ทุกคน (Anyone) เพื่อเปิดช่องทางการสื่อสารกับฮาร์ดแวร์
คัดลอกและบันทึกค่า Web App URL ที่ระบบสร้างขึ้น เพื่อนำไปใช้งานในขั้นตอนการตั้งค่าไมโครคอนโทรลเลอร์
3.3 การตั้งค่าไมโครคอนโทรลเลอร์ (ESP32 Configuration)
เปิดไฟล์ AutoCatFeeder.ino ผ่านโปรแกรม Arduino IDE
แก้ไขข้อมูลการเชื่อมต่อเครือข่ายไร้สายในตัวแปร ssid และ password ให้ตรงกับข้อมูลของเครือข่ายที่ต้องการใช้งาน
นำ Web App URL ที่ได้รับจากขั้นตอนที่ 3.2 ไปกำหนดค่าลงในตัวแปร WebApp_URL
ตรวจสอบความถูกต้องของการกำหนดพอร์ต (Pin Mapping) ให้สอดคล้องกับการต่อวงจรจริง (เช่น TRIG_PIN 21, ECHO_PIN 18 และ SERVO_PIN 13)
เลือกบอร์ดประมวลผล (ESP32 Dev Module) และพอร์ตเชื่อมต่อให้ถูกต้อง จากนั้นดำเนินการคอมไพล์และอัปโหลด (Upload) ซอร์สโค้ดลงสู่ไมโครคอนโทรลเลอร์
4. การทดสอบการทำงานของระบบ (System Operation & Verification) เมื่อกระบวนการติดตั้งฮาร์ดแวร์และซอฟต์แวร์เสร็จสิ้น ระบบจะพร้อมปฏิบัติงานตามสถาปัตยกรรมที่ออกแบบไว้ โดยผู้ปฏิบัติงานสามารถทดสอบระบบได้ผ่านเบราว์เซอร์ด้วย Web App URL การทดสอบจะครอบคลุมถึงการตั้งค่าโปรไฟล์สัตว์เลี้ยง การประเมินโควตาอาหารอัตโนมัติจาก AI การตอบสนองของเซนเซอร์เทียบกับเงื่อนไขการจ่ายอาหารที่กำหนดไว้ในโปรแกรม และการสั่งให้อาหารโดยผู้ใช้ผ่านเว็บ
